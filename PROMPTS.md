# AI Prompt Usage

This document outlines how AI assistance and prompting were used throughout the development process of the Credex AI Spend Audit project.

---

# Goals of AI Usage

AI tools were primarily used to:
- accelerate debugging
- improve architectural decision making
- refine UI structure
- troubleshoot deployment issues
- improve development workflow efficiency

The final implementation, integration, debugging, and architectural decisions were manually reviewed and adapted during development.

---

# Example Prompt Categories

## UI & UX Prompts

Examples:
- "Improve the SaaS-style UI layout for an AI audit dashboard"
- "Suggest modern Tailwind card designs for analytics display"
- "How can I center and structure a responsive Next.js form?"

Used for:
- layout refinement
- Tailwind improvements
- responsive structure ideas

---

# Backend & Database Prompts

Examples:
- "How should MongoDB persistence be structured in Next.js App Router?"
- "Create a reusable Mongoose connection utility"
- "How do dynamic API routes work in Next.js?"

Used for:
- API route architecture
- MongoDB integration
- schema structure
- server-side rendering flow

---

# Debugging Prompts

Examples:
- "Why is MongoDB Atlas timing out in Next.js?"
- "How do I fix async params issues in Next.js dynamic routes?"
- "Why am I getting a 500 error from my API route?"

Used for:
- deployment troubleshooting
- route debugging
- environment variable fixes
- production debugging

---

# Product Thinking Prompts

Examples:
- "What features make an AI SaaS MVP feel realistic?"
- "How can shareable reports improve UX?"
- "What documentation files are important for engineering evaluations?"

Used for:
- prioritization
- MVP scoping
- assignment strategy
- UX flow improvements

---

# Key Takeaways

AI assistance significantly accelerated:
- debugging speed
- implementation planning
- documentation structure
- iterative development

However, building the final working system still required:
- manual debugging
- architecture adjustments
- deployment troubleshooting
- integration testing
- iterative refinement

---

# Philosophy

AI was used as a development accelerator and brainstorming assistant rather than a replacement for engineering decisions.

The project development process still required understanding:
- system architecture
- state management
- backend integration
- deployment workflows
- production debugging
